# SOBIMON 이미지 폴더 가이드 (public/images/sobimon)

이 폴더에 아래의 파일명으로 이미지(PNG, JPG, WebP)를 넣어주시면, 앱 내의 해당 영역에 자동으로 1:1 매칭되어 표시됩니다.
만약 이미지가 없거나 로드되지 않을 경우, 자동으로 완성형 고화질 벡터 일러스트가 폴백(Fallback)으로 작동하므로 이미지가 깨지지 않습니다.
